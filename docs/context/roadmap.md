# Roadmap

## v0.1 implemented

- Fixed per-run grants, a single gateway dispatch entry point, and three local adapters.
- Benign and suspicious offline replays with independent execution evidence.
- Local dashboard, versioned JSON export, and automated verification.

## Possible follow-on work

A future MCP integration could translate protocol tool calls into the existing gateway entry point and test that the same grant checks apply. This is an unscheduled follow-on option.

Live models, general-purpose detection, configurable policies, durable storage, and public deployment authentication are outside v0.1. See the [v0.1 product claims](product.md).
